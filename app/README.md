# Interactive Application Directory (R Shiny)

**Status:** Placeholder for Phase 5 (Out of scope for Phase 0 & Phase 1).

This directory will host an interactive R Shiny web application designed for students and evaluators to explore the final canonical datasets:
- `UAQI_Hyderabad_Daily.csv`
- `UAQI_India_Daily.csv`

### Planned Application Capabilities:
1. **Interactive Station Map:** Visualizing monitoring stations across Hyderabad and India with live color-coded AQI status.
2. **Time-Series & Trend Explorer:** Allowing interactive date filtering, pollutant comparisons, and seasonal cycle visualization.
3. **Pollutant Drift Visualizer:** Displaying dynamic rolling mean comparisons and percentage drift across selected temporal windows.
4. **Statistical Diagnostics:** Interactive QQ-plots, correlation heatmaps between pollutants and meteorological variables, and regression residual summaries.
