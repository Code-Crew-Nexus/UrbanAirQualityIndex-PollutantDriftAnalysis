Methodological Integrity & Scientific Freeze

All statistical and machine learning model development is permanently frozen at tag v0.6-svm-freeze. The website acts strictly as a lightweight, zero-dependency presentation layer that consumes serialized results produced by the R computational engine.

  • CPCB-Aligned Verified-Subset AQI: Uses only AQI inputs whose source units were directly verified (PM2.5, PM10, and O3).
  • Chronological Model Selection: Model hyperparameters were selected across Train (through Dec 2025) and Validation (Jan–Apr 2026); for locked holdout evaluation, selected specifications were subsequently refitted on permitted history according to frozen protocols.
  • Reproducibility: All seeds, hyperparameter grids, and split indices are permanently archived and audited.
