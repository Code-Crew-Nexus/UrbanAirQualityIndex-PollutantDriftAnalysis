Decision Threshold & Margin Semantics: Operating rules differ across model paradigms: Logistic Model B evaluates an estimated adverse-event probability (estimated conditional probability of AQI(t+1) > 100) against a validation-selected threshold (p* ≈ 0.311268 in Hyderabad, p* ≈ 0.713448 in India). RBF SVM evaluates an uncalibrated signed decision score s(x), where s(x) = 0 is the native classification boundary. Persistence serves as a deterministic current-day adverse-state benchmark: AQI(t) > 100. Brier score is reported for Logistic probability predictions and the binary 0/1 persistence benchmark (SVM decision scores are non-probabilistic, so SVM Brier score remains null).
